# CARE

An AI skincare guidance idea: describe or scan a skin problem, get the likely cause and a routine, and only then see product suggestions. Clarity first, not selling products.

**Status:** landing page only. There is no app yet. Source code is not uploaded yet. Write-up: https://abhiraajr.github.io/projects/care.html

## What exists
- React + TypeScript + Vite coming-soon site with a three-step waitlist (email, optional survey, thank-you)
- Answers go to a Google Apps Script endpoint

## Decisions
- Dropped dropshipping (returns, refunds, liability); leaning toward affiliate links
- The app must never diagnose, and should point people to a doctor for warning signs
